# Vibe Vision Video documentation

Build a template once and reuse it across projects and coding agents. A VVV template holds the scene code, photo slots, copy fields, timing and checks; each project holds its own materials and edits. The template library currently focuses on wedding films.

## Make a video

- [Getting started](getting-started.md): install the skill, say what you want, review the sample, get the film.
- [Templates](templates.md): the five templates, styles to choose from, formats, previews and the effect.

- [Integrations](integrations.md): musicdl, 百度网盘 and TikHub, what each does and how VVV uses it.
