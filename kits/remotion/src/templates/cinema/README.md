# Cinema · 黑幕影院婚礼开场

`VVV-Cinema` 是给婚礼现场大屏用的黑底开场片，16:9，约 1 分 55 秒（随配乐节拍略有变化）。顺序是：黄昏天空上打字“欢迎来到我们的婚礼 / 这是属于我们的故事” → 两张圆角童年照，配新郎新娘姓名与生日 → 四张童年照从两侧滑进一排 → 画一条线、打出相遇日期，第一张合照从这条线里展开成满屏 → “我们已经一起走过 N 天”数字跑上去 → 恋爱照片三栏一栏一栏铺满、再换一组 → 一句话 → 又一组三栏 → 一句话 → 婚纱满屏 → 两张并排、再换一对 → 三栏 → 两行打字 → 笑脸近景 → 线描新人与致谢。

版面和动作按参考片（现场大屏的手机录像）逐 0.25 秒实测：标题一字一字打出、带方块光标，打完后光标随半拍闪烁；照片按拍一栏一栏淡入，童年照和婚纱双图从两侧滑入，滑动提前 0.42 拍开始，让变化最大的一刻落在拍点上；每页在倒数第二拍淡出。黑底上有一层缓慢飘动的柔光点（像放映光束里的灰尘），只有文字的页面也不会定格。

黄昏天空和线描新人（`public/assets/cinema/`）是生成的图片；所有文字都可编辑。柔光点是代码画的（几个径向渐变圆），不来自参考片。

每页占 8、12 或 16 拍（`index.tsx` 的 `PAGES`），按整小节排布；`pace` 让每页按倍数变长。

在 `inputs.json` 的 `props` 中编辑：

- `couple`：新人姓名与婚礼日期；`groomBorn`、`brideBorn` 是童年页的生日；`since` 是相遇或在一起的日期，相遇页显示它，计数页算到婚礼日期的天数。
- `photos`：10 个槽位共 25 张，要求见 [目录](../../../catalog/cinema.json) 的 `hint`。童年照可以是横图或竖图，会裁成圆角方形。
- `copy`：所有文字。用 `｜` 分行。
- `music`：默认 *Possible Dreams*（Mixkit，需 `npm run music`）。换自己的音乐后运行 `npm run beats -- public/music/<文件>`，所有页面会跟着新节拍重新排布。
