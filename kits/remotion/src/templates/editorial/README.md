# Editorial · 简约留白杂志婚礼 MV

`VVV-Editorial` 是白纸上的杂志排版婚礼 MV，16:9，约 85 秒（随配乐节拍略有变化）。14 个版面依次是：手写红字封面 → 圆形双人请柬（弧形英文、丝带蝴蝶结）→ 照片配诗句 → 三联图上浮 → 双图两组 → 居中诗句 → 双图配打字说明 → 爱心展开满屏 → 横竖双图配囍字 → 竖排 WE GOT MARRIED → 三栏长图生长再换一组 → 三图拼贴 → 手写“浪漫主义者” → 誓言与 THANK YOU。

版面坐标按参考片的定格画面实测（1920×1080）。动作语言也照参考片：照片大多“画面不动、从一条边向内展开”，封面和三联图滑入，结尾照片从中心的小卡片放大归位；文字逐字淡入；两组手写大字从轻微模糊中淡入；同一版换一组照片用双重曝光式溶接；换页时一团半透明白色泡泡从左往右扫过，把整页溶进白纸，下一页在扫过的地方开始搭建。

两组手写大字（封面“我们的婚礼”、手写页“永远的浪漫主义者”）是生成的笔迹图片（`public/assets/editorial/`）。`copy.cover_title`、`copy.romance_title` 保持默认时显示这两张图；改成别的文字后自动改用打包的 Long Cang 手写字体排出来。

每个版面占 8 或 16 拍（`index.tsx` 的 `PAGES`），边界落在 8 拍乐句上；版面在最后一拍被一排柔白光斑从左到右擦掉，下一版在干净的白纸上搭起来。照片的滑入、放大在节拍前 `LEAD`（0.42 拍）开始，这样画面变化最大的一刻正好落在拍点上。

在 `inputs.json` 的 `props` 中编辑：

- `couple`：新人姓名与日期；`tagline` 是封面右上角的小字。
- `photos`：14 个槽位共 31 张，每个槽位的方向要求见 [目录](../../../catalog/editorial.json) 的 `hint`。照片按人脸自动裁切；竖版版面放横图会裁掉两侧。
- `copy`：所有文案。用 `｜` 分行，`｜｜` 空一段。每行尽量不超过 12 个汉字，过长会自动缩小字号。
- `music`：默认 *When in Love*（Mixkit，需 `npm run music`）。换自己的音乐后运行 `npm run beats -- public/music/<文件>`，所有版面会跟着新节拍重新排布。

修改动作后重新渲染并用 `vvv check` 复测卡点；入场改成错开半拍时，峰值会落在两拍之间。
