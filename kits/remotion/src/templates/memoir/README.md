# Memoir · 手写胶片故事婚礼开场

`VVV-Memoir` 用黑底手写体讲两个人的一生，16:9，约 2 分 35 秒（随配乐节拍略有变化）。顺序是：打字“欢迎来到我们的婚礼” → 胶片框里的合照配两句话 → 新人贴纸、彩纸飘落和感谢 → 家乡地标与童年照贴纸、手写名字和箭头 → 滚动的 35mm 胶片上的童年 → “直到 {相识日期}” → 聊天截图与认识经过 → 四个章节（标题 + 两张照片） → 领证：先打字，再在相机取景框（REC、4K 60FPS）里出照片 → “爱是什么”与四页照片配手写句子和底部小字 → 一封长信 → 致谢与署名。

版面和动作按参考片逐帧实测：手写字一字一字打出、带细光标；贴纸弹出后轻轻摆动；胶片条每四拍前进一格，每次前进从拍点开始（整条移动在起步时变化最大）；章节照片的淡入以拍点为中心；每页在倒数第二拍淡出。黑底上有缓慢飘动的柔光点，长信会随书写缓缓上移，所以只有文字的页面也不会定格。

胶片框和手绘箭头（`public/assets/memoir/`）是生成的图片；胶片条、贴纸描边、彩纸和取景框是代码画的。所有文字都可编辑。

**贴纸效果**：`couple`、`homeGroom`、`homeBride`、`kidGroom`、`kidBride` 放抠好背景的 PNG 时，会显示成带白边和彩色描边的贴纸（新郎一侧蓝色、新娘一侧红色）；普通照片会显示成带同样描边的卡片。需要抠图时，用图像生成把照片抠成透明背景再放进来。

每页占 8、12、16 或 32 拍（`index.tsx` 的 `PAGES`），按整小节排布；`pace` 让每页按倍数变长。

在 `inputs.json` 的 `props` 中编辑：

- `couple`：新人姓名与婚礼日期（出生页的手写名字、结尾署名）；`since` 是相识日期，时间跳转页显示。
- `photos`：17 个槽位共 37 张，要求见 [目录](../../../catalog/memoir.json) 的 `hint`。
- `copy`：所有文字，用 `｜` 分行。出生页的标题、两地家乡、章节标题、“爱是什么”的句子和底部小字、长信都在这里。
- `music`：默认 *First Kiss*（Mixkit，需 `npm run music`）。换自己的音乐后运行 `npm run beats -- public/music/<文件>`，所有页面会跟着新节拍重新排布。
